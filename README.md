# 付款提审台

面向媒介项目费控的飞书多维表格自定义插件。用户在【付款执行明细】中勾选记录后，可以在插件内完成批次预检、附件归集、审批发起和状态回填。

## 核心流程

1. 读取当前表中 `申请付款选择框 = true` 的记录。
2. 校验同一资源、项目一致性、验收、合同、发票、附件和成本。
3. 生成付款批次 CSV，下载 Base 附件并上传为飞书审批附件。
4. 云账户付款自动发起原生审批并回填实例 Code；项目付款因 `account` 控件限制，自动备齐附件后打开原生审批补选账户。
5. 同步审批状态和流程编号到付款执行明细。

## 身份与权限

- 妙搭负责应用登录和运行时访问控制。
- 首次发起审批时，用户通过飞书 OAuth 授权；后续使用加密 HttpOnly Cookie 自动续期。
- 审批发起人是当前操作用户，不依赖个人电脑、CLI 或 Agent。
- App Secret、会话密钥、Base Token 和审批 Code 均通过妙搭环境变量注入。
